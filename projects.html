04 Editorial Web Design

Indiana Daily Student

Two interactive editorial features, designed and built inside an existing publication template.

I designed and built two responsive multimedia web experiences with HTML, CSS, and JavaScript, working inside an existing publication template rather than from a blank canvas, customizing layout, content hierarchy, and media placement for long-form features that reached 10,000+ monthly readers.

The real work was in the constraints: structuring scroll flow, pacing images against text, and making responsive decisions that held up on both desktop and mobile, while adapting one shared template into two distinct reader experiences for two sensitive, narrative-driven stories.

06 Product Exploration / Concept

Verified Crew is a concept for a verification layer on top of a crew-matching platform, not a feature that exists today.
