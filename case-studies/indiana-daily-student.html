Indiana Daily Student

Before enterprise tech, I was building for a real, public audience.

Co-design Co-development Long-form storytelling
Context

I designed and built two responsive multimedia web experiences with HTML, CSS, and JavaScript, working inside an existing publication template rather than from a blank canvas, on features that reached 10,000+ monthly readers.

The real design work was in the constraints: structuring scroll flow, pacing images against text, and making independent UX decisions within a shared template, all to balance storytelling with usability across desktop and mobile.
