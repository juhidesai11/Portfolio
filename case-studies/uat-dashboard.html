UAT Dashboard

Making testing progress easier to see.

During an Oracle Cloud implementation, I built a Jira/Xray workflow and dashboard that organized UAT testing by ownership, workstream, module, and status, giving the team a real-time view of progress and exceptions.

Jira + Xray·UAT·Oracle Cloud

Clearer information
for better decisions.

The Problem

Testing was happening.
Visibility wasn’t.

UAT involved multiple workstreams and testers working through a large set of test scripts. Before daily touchpoints, the team needed to quickly answer:

  • What’s done?

    Successful tests

  • What’s left?

    Not started / outstanding tests

  • What’s broken?

    Defects

  • Where?

    Module / workstream

  • Who owns it?

    Tester / owner

The Solution

A simple workflow
for a complex process.

I structured the existing Jira/Xray setup to give the team a clear, real-time view of UAT progress.

  1. 01Organized test scripts by module and workstream
  2. 02Assigned test cases to testers
  3. 03Standardized testing statuses
  4. 04Created filters and built a live Jira dashboard
  5. 05Used the dashboard in daily UAT touchpoints
Impact

From manual prep
to a live view.

The team could go directly into the dashboard before daily UAT touchpoints and immediately see where testing stood and what needed attention, rather than manually piecing together progress across test cases.

The workflow provided clearer visibility into testing progress and exceptions as the team moved toward cutover and production go-live.

My Role

UAT workflow +
dashboard design

  • Structured Xray test scripts and ownership
  • Assigned test cases across workstreams
  • Defined testing statuses and filtering logic
  • Built the Jira dashboard
  • Created views around the questions stakeholders needed to answer
  • Supported daily UAT visibility through cutover
Takeaway

Good tools make it easier to act on what you already know.

This project reinforced the importance of designing around the decisions people need to make, not just the data that is available.
