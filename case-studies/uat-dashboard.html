Project Tooling / Oracle Cloud Implementation / PwC

From test scripts
to go-live visibility.

During UAT, testing was happening across multiple modules, workstreams, and testers. The challenge wasn’t a lack of information. It was quickly understanding where testing stood, what needed attention, and whether the team was on track for cutover.

I built a live Jira/Xray workflow that organized testing around ownership, workstream, module, and status, giving the team a real-time view of UAT progress and exceptions.

Jira + Xray·UAT·Oracle Cloud implementation
The Problem

Testing was happening.
Visibility wasn’t.

UAT involved multiple workstreams and testers working through a large set of Xray test scripts. Results were being recorded. The harder part was seeing them as one picture. Five questions came up again and again.

Q1What’s done?Successful tests
Q2What’s left?Not started / outstanding tests
Q3What’s broken?Defects
Q4Where?Module / workstream
Q5Who owns it?Tester / owner

The information existed in Jira/Xray. The challenge was making it easy to interrogate.

What I Built

A live view of testing,
not a static report.

01Structure

Organized Xray test scripts across modules and workstreams.

02Assign

Assigned test cases to testers based on workstream and ownership.

03Track

Established clear testing states including Not Started, Tested, Successful, and Defects.

04Filter

Created custom views by module, workstream, owner, status, successful tests, and defects.

05Monitor

Connected the workflow through a live Jira dashboard that changed as testers updated their work.

The Product-Thinking Piece

I designed around the decisions,
not the data.

The important question wasn’t “What information can I put on a dashboard?”

It was: “What does the team need to know when they walk into the daily UAT touchpoint?”

Different stakeholders needed different slices of the same testing data. Instead of creating one static report, I created filters that allowed the team to move from the full testing population to the specific slice they needed to investigate.

Takeaway

A useful product doesn’t always create more information.

Sometimes it makes the information you already have easier to act on.

This project changed how I think about dashboards: the value isn’t in displaying everything. It’s in helping someone find the right information at the moment they need to make a decision.
